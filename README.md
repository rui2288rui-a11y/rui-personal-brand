# RUI Personal Brand

AI × WEB × IT × BUSINESS × BRAND をテーマにした個人ブランドサイトの初期版です。

## ファイル
- index.html — ページ本体
- style.css — デザイン
- script.js — スクロール表示・カーソル演出など

## GitHubで公開する
1. GitHubで新しいRepositoryを作成
2. この3ファイルをアップロード
3. Settings → Pages からGitHub Pagesを有効化
4. Branchは `main` / `/ (root)` を選択

## 変更する場所
- メールアドレス: `index.html` の `hello@example.com`
- 自己紹介: ABOUT
- サービス: BUSINESS
- 実績: PROJECTS
- 更新履歴: JOURNAL

※会社名はまだ設定していません。後からブランド名に置き換えられます。
